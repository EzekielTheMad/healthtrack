# Synthetic gym-import fixtures

All values, timestamps, notes and identifiers in these three JSON files are
hand-authored fiction. They are generated by
[`generate-synthetic-gym-fixtures.ts`](../../generate-synthetic-gym-fixtures.ts).
They are not a redacted or shifted copy of a person's health export.

The 4 sessions, 11 exercise entries and 2 weekly check-ins cover relation order,
back-link fallback, aliases, warmups, per-arm loads, timed sets, multipliers,
working-weight mismatch reporting, cardio parsing, a populated week and an
empty week. The intentional weight mismatch and missing forward relation are
test cases. Every reference resolves to another synthetic record.

To regenerate with Node 22+:

```sh
node --experimental-strip-types scripts/generate-synthetic-gym-fixtures.ts
```

The privacy tests require exact agreement with this generator, synthetic IDs,
fictional dates, no source URLs, and consistent references. Do not add a real
export, even with names removed. Invent a minimal case in the generator instead.
A passing test does not prove the rest of the repository or its history is free
of personal data.
